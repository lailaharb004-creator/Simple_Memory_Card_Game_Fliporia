# 🎮 Fliporia

Fliporia is a fun memory card matching game built using HTML, CSS, JavaScript, and Bootstrap.

The goal of the game is simple:
Flip the cards, remember the emojis, and find all matching pairs with the fewest moves possible.

---

# ✨ Features

- Responsive design for desktop and mobile
- Animated card flip effect
- Random emoji shuffle every game
- Move counter
- Retry button
- Glassmorphism-inspired UI
- Smooth hover and transition effects

---

# 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Bootstrap 5
- Font Awesome
- Google Fonts

---

# 🎯 How to Play

1. Click on a card to reveal the emoji.
2. Flip a second card.
3. If the emojis match, the cards stay open.
4. If they don't match, the cards flip back.
5. Match all pairs to win the game.
